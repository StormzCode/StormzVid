StormzVid icons
===============
Drop your image files in THIS folder. Names are not case-sensitive. Best: square, transparent
background PNG, 128x128 or 256x256 px. .svg, .webp and .jpg also work.
Refresh the page after adding a file (no restart needed). Missing icons show a coloured letter tile.

SITE
  Stormz.png        logo in the header and footer (also used as tab icon if there is no .ico)
  stormz.ico        browser-tab icon (favicon)

PLATFORMS
  yt.png            YouTube
  ig.png            Instagram
  tiktok.png        TikTok
  fb.png            Facebook
  snap.png          Snapchat
  x.png             X (Twitter)
  reddit.png        Reddit
  twitch.png        Twitch
